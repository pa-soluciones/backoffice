# 10 — Asistencia de IA

## 1. Principios
1. **La IA asiste, no decide.** Toda propuesta se muestra y el usuario la acepta o descarta.
2. **Solo texto.** La IA edita bloques de texto de documentos. Nunca escribe IDs, clientes, cantidades, precios ni totales (D10).
3. **A pedido.** No hay generación automática en segundo plano; se activa con un botón.
4. **Agnóstica de proveedor.** Cambiar de proveedor es configuración, no código.

## 2. Configuración

**RF-IA-01 [M]** Ajustes → IA (permiso `configuracion.escribir`):
- Proveedor: Anthropic · OpenAI · Google · Compatible con OpenAI (URL base: OpenRouter, Ollama, LM Studio, etc.).
- Modelo (texto libre + sugerencias por proveedor).
- API key: se guarda cifrada (AES-256-GCM con `ENCRYPTION_KEY`), nunca se devuelve al navegador (solo `••••1234`).
- Botón "Probar conexión".
- Límite mensual opcional de tokens/costo estimado; al superarlo se deshabilita la IA y se avisa a los admins.
**RF-IA-02 [M]** Implementación con Vercel AI SDK y un registro de proveedores (`ai/registry.ts`). Si no hay configuración, los botones ✨ se ocultan.
**RF-IA-03 [S]** Modelo distinto por función (ej. uno barato para "corregir ortografía").

## 3. Casos de uso

| # | Caso | Entrada | Salida | Prioridad |
|---|---|---|---|---|
| IA-1 | Ajustar un párrafo | Bloque + instrucción | Texto del bloque | [M] |
| IA-2 | Acciones rápidas (mejorar, acortar, formalizar, ortografía) | Bloque | Texto del bloque | [M] |
| IA-3 | Revisar documento completo | Todos los bloques editables | Propuesta por bloque | [M] |
| IA-4 | Redactar descripción técnica desde notas de visita / pedido del prospecto | Notas, ítems, fotos (descripción) | Bloque "descripción técnica" | [M] |
| IA-5 | Redactar observaciones del Control de Perforaciones | Balance calculado | Bloque "observaciones" | [M] |
| IA-6 | Redactar texto explicativo de un adicional / certificación | Ítems del adicional, presupuesto de referencia | Bloque | [M] |
| IA-7 | Sugerir precios | Ítem + historial de presupuestos similares (mismo tipo, Ø, espesor, últimos 12 meses) | Rango sugerido + presupuestos fuente | [S], **desactivado por defecto** |
| IA-8 | Proponer subtítulo de control ("Pisos 17 al 2") | Registros | Texto corto | [S] |

**RF-IA-04 [M]** IA-7 nunca escribe el precio: muestra "Sugerido: $160.000 – $175.000 (basado en 2026/0098, 2026/0101)" y el usuario lo carga. Se activa en Ajustes → IA.

## 4. Contrato de la API interna

```ts
// POST /api/ia/bloque  (stream)
request:  { documentoId, versionId, bloqueId, accion: 'instruccion'|'mejorar'|'acortar'|'formal'|'ortografia'|'desde_notas', instruccion?: string }
response: { bloqueId, texto }   // solo texto; el servidor descarta cualquier otra cosa
```

- El **prompt de sistema** incluye: rol (redactor técnico-comercial de PAS, español rioplatense formal, "Uds."), glosario técnico (H°A°, Ø, sistema diamantado, Ajuste Alzado, Base CAC), las variables permitidas (`{cliente}`, …) y la regla: "no inventar cifras, medidas ni nombres que no estén en el contexto".
- El contexto incluye **solo** los datos que el usuario puede ver (sin montos si no tiene `ver_montos`).
- Post-validación: si el texto devuelto contiene números que no estaban en el contexto (montos, Ø, cantidades), se marca con advertencia "La IA agregó cifras: revisar".

## 5. Registro y costos
**RF-IA-05 [M]** Cada llamada registra: usuario, función, proveedor, modelo, tokens de entrada/salida, duración, documento. Ajustes → IA muestra el consumo del mes.
**RF-IA-06 [M]** Permiso `ia.escribir` para usar el asistente.

## 6. Criterios de aceptación
- [ ] Cambiar de Anthropic a OpenAI en Ajustes funciona sin deploy.
- [ ] La respuesta de IA-1 solo modifica el bloque elegido.
- [ ] Un usuario sin `ver_montos` usando IA-3 no envía importes al proveedor (verificable en el log del prompt).
